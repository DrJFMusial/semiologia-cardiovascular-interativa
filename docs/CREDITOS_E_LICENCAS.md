## Sons

Todos os sons são sintetizados no navegador pelo código deste projeto (`src/core/audio.js`) e identificados na tela como "Som sintetizado esquemático". Não são registros fonocardiográficos clínicos. Nenhuma gravação de terceiros foi incluída.
